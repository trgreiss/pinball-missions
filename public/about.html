About Pinball Missions

When you're still learning a machine's layout and code, it's hard to get deep into the rules. Pinball Missions gives each game a focus: start a particular mode, light a jackpot, chase a wizard mode.

Where objectives come from

  • Every objective is derived from that machine's rulesheet on pinballrulesheets.com, the community wiki that continues the TiltForums rulesheets.
  • Rulesheets are imported into a database a few times a year, when new machines or major code updates come out. They are not fetched live.
  • Objectives were drafted automatically from the rulesheet text. If one doesn't match the game in front of you (code updates change rules), follow its rulesheet link and trust the rulesheet.

Questlines

Rules in modern games build on each other, so objectives are organized as questlines: ordered chains that follow the rulesheet's own progression. For example, Godzilla's Mechagodzilla Multiball questline:

  1. Bring Mechagodzilla online
  2. Disable the Neo Barrier
  3. Start Mechagodzilla Multiball
  4. Collect jackpots to light the super jackpot
  5. Score the super jackpot
  6. Light and start Terror of Mechagodzilla (mini-wizard mode)

Missions show the whole chain, because you can't pause mid-game to check what's next. Your progress carries over: choose Continue ones I've started to pick up where you left off.

Pro, Premium and LE

Some steps exist only on one model of a machine. Set each machine's model on the Machines page (Pinball Map imports fill it in when the venue lists it) and steps for other models are hidden. Until you do, every step shows, with a tag on the model-specific ones.
